
# Personal Expense Tracker

## Project Description

Personal Expense Tracker is a Python-based application that helps users manage their daily expenses. Users can add, view, delete expenses, calculate total spending, and check their expenses against a fixed budget.

## Features

- Add new expenses
- View all expenses
- Calculate total expenses
- Delete expenses
- Check budget
- Save expense records using JSON
- Load previously saved expenses

## How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the following command:

```bash
python main.py
```

## How to Use

1. Select Add Expense to enter expense details.
2. Select View Expenses to see all records.
3. Select Total Expenses to calculate spending.
4. Select Delete Expense to remove a record.
5. Select Check Budget to check your spending.
6. Select Exit to close the application.
